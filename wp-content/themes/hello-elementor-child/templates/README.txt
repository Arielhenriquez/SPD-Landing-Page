Plantilla HTML de referencia para página de proyecto individual.

- project-single.html: estructura HTML completa (hero, overview, gallery, related).
  En WordPress se usa la plantilla PHP "Project Single" (template-single-project.php)
  que genera este mismo HTML con los datos de inc/projects-data.php.

  Puedes usar este .html como referencia o para pegar el bloque interior en un
  bloque "HTML personalizado" si en algún momento quieres editarlo a mano.
