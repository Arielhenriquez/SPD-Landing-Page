CSS por página
==============

Cada archivo aquí se carga SOLO en la página cuyo slug coincide con el nombre del archivo.

- Nombre del archivo = slug de la página en WordPress (sin espacios, minúsculas).
- Ejemplos:
  - home.css       → se carga solo en la página con slug "home"
  - contact-us.css → se carga solo en la página con slug "contact-us"
  - about.css      → se carga solo en la página con slug "about"

Para ver el slug de una página: Panel → Páginas → editar la página → en la URL verás post=XXX, o en "Enlace permanente" verás /slug-de-la-pagina/

Crea un archivo .css con el mismo nombre que el slug y escribe tus estilos ahí.
